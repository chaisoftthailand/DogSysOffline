# DogSysOffline
ระบบคลินิครักษาสัตว์(สุนัข)<br>
ระบบนี้จะมีระบบการบันทึกข้อมูลแบบ Online/Offline ในกรณีที่สัญญานอินเตอร์เน็ตขาดหายไป ก็สามารถบันทึกข้อมูลได้<br>
<ul><ol>
<li>🐶 บันทึกข้อมูลสัตว์ส่งรักษา :เพิ่ม/แก้ไข/ดูประวัติสุนัข (ส่วนนี้สามารถใช้งานได้ทั้งระบบ Online/Offline)
<li>💉 การรักษาพยาบาล : บันทึกการรักษาและประวัติการรักษา (ส่วนนี้สามารถใช้งานได้ทั้งระบบ Online/Offline)
<li>📅 การจัดการผู้ใช้งานนัดหมาย : ระบบนัดหมายและแจ้งเตือน (ส่วนนี้สามารถใช้งานได้ทั้งระบบ Online/Offline)
<li>📊 รายงาน : รายงานการรักษาและการทำงานของคลินิก
<li>🏥 ข้อมูลคลินิก : เพิ่มคลินิก/ผู้ดูแลระบบ
<li>👤 จัดการผู้ใช้งาน : สิทธิ์การใช้งานและผู้ดูแล (ส่วนนี้สามารถใช้งานได้ทั้งระบบ Online/Offline)
</ul>
